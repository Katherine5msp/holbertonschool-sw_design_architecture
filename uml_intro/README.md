
# Introduction to UML Modeling

This directory contains UML modeling exercises for a
Library Loan System, using Mermaid syntax.

## Tasks

- Task 0: Class Diagram
- Task 1: Sequence Diagram
- Task 2: Concept Validation Quiz

## Classes

- Library
- Book
- User
- Loan

## Learning Objectives

- Identify classes, attributes, and methods.
- Model UML relationships and multiplicities.
- Create class and sequence diagrams using Mermaid.
